# Публикация опыта на бесплатном GitHub Pages

В папке лежит готовый сайт:

- `index.html` — самодостаточная страница опыта (HTML + CSS + JS + SVG в одном файле, без внешних зависимостей);
- `EXPERTISE.md` — отчёт экспертизы (физика и методика);
- `README.md` — эта инструкция.

## 1. Создайте репозиторий

1. Войдите в GitHub → **New repository**.
2. Repository name: например `utubka-physics` (латиницей, без пробелов).
3. Выберите **Public** — бесплатный GitHub Pages работает для публичных репозиториев.
4. Не ставьте галочки «Add a README / .gitignore / license» — загрузите свои файлы.
5. **Create repository**.

## 2. Загрузите файлы

Самый простой способ — через веб-интерфейс:

1. На странице репозитория нажмите **Add file → Upload files**.
2. Перетащите `index.html` (и при желании `EXPERTISE.md`, `README.md`).
3. **Commit changes**.

Через Git:

```bash
git clone https://github.com/ВАСЬ/utubka-physics.git
cd utubka-physics
# положите index.html сюда
git add index.html
git commit -m "Add U-tube physics lab"
git push
```

## 3. Включите GitHub Pages

1. Откройте репозиторий → **Settings** → слева **Pages**.
2. **Build and deployment**:
   - Source: **Deploy from a branch**;
   - Branch: **main** (или `master`), папка **/(root)**;
   - **Save**.
3. Через 1–2 минуты страница будет доступна по адресу:

```
https://ВАСЬ.github.io/utubka-physics/
```

где `ВАСЬ` — ваш логин GitHub, а `utubka-physics` — имя репозитория.

## 4. Проверка на телефоне

- Откройте ссылку в браузере телефона (Wi‑Fi или мобильный интернет).
- Проверьте: нет горизонтальной прокрутки, кнопки нажимаются пальцем, прохождение всех шагов до конца.
- Чтобы школьники заходили по QR-коду: скопируйте адрес сайта в любой бесплатный генератор QR (например, qr-code-generator.com) и распечатайте код.
- Можно «Добавить на главный экран» — страница откроется как приложение.

## 5. Обновление материала

После правок `index.html` просто загрузите новую версию в репозиторий (или сделайте `git add/commit/push`). GitHub Pages обновит сайт автоматически в течение 1–2 минут.

## 6. Важные замечания

- Файл полностью автономен: его можно также отправить школьникам напрямую (Telegram, почта, флешка) — он откроется без интернета.
- В репозитории не нужно хранить оригинал из `@Z` — улучшенная версия полностью его заменяет.
- Если нужен русский адрес или свой домен — это уже платные/дополнительные опции; для школьного стенда достаточно `*.github.io`.
